Privacy policy

Effective 5 November 2026

This policy covers this website and SI b Darija Studio, the publishing tool that SI b Darija uses to post its own videos. SI b Darija is run by Abdelaziz Saqqal in Morocco. Questions about this policy go to seqqal.abdelaziz@gmail.com.

What SI b Darija Studio is

SI b Darija Studio is a private tool that runs on the owner's own computer. It uploads videos made by SI b Darija to SI b Darija's own accounts on YouTube, Instagram and TikTok, after the owner approves each post. It is not offered to the public, and only the owner signs in to it.

Data the tool accesses

  • YouTube (through YouTube API Services): the channel ID and channel name, to confirm that uploads go to the SI b Darija channel, and permission to upload videos to that channel.
  • Instagram (through the Instagram Graph API): the account ID and username of the SI b Darija account, and permission to publish to it.
  • TikTok (through the TikTok Content Posting API): the basic profile of the SI b Darija account, and permission to publish to it.
  • For each platform, the access tokens that the platform issues when the owner signs in.

The tool does not read viewers' personal data, comments, messages, contacts or analytics, and it does not access any account other than SI b Darija's own.

How the data is used and stored

  • The data is used only to publish SI b Darija's videos and to confirm that each post went to the right account.
  • Tokens and account IDs are stored in a local file on the owner's computer, readable only by the owner's user account. They are sent only to the platform that issued them, never to any other server.
  • The tool has no analytics, no advertising and no tracking.

Sharing

SI b Darija does not sell, rent or share data with anyone. Data obtained from one platform is sent only back to that same platform.

Keeping and deleting data

Tokens are kept until access is revoked or the local file is deleted. Access to YouTube can be revoked at any time from Google's security settings at security.google.com/settings/security/permissions. Revoking access or deleting the local file removes the tool's ability to use the account. To ask about or delete any data, write to the email address above.

YouTube API Services

SI b Darija Studio uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

This website

This website sets no cookies and runs no analytics or third-party scripts. It is hosted on GitHub Pages, and GitHub may log visitors' IP addresses for security, as described in the GitHub General Privacy Statement.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
